Studio Tomahawk is a French publisher. It made [Mars: Code Aurora](/games/mars-code-aurora/), a generic sci-fi skirmish game that North Star Military Figures publishes in English.

Its [own site](https://www.studio-tomahawk.com/) lists the game worlds it covers: Saga, Mousquets & Tomahawks, Dracula's America, Jugula, Frostgrave 2nd édition, Congo, V for Victory, and Stargrave. Mars: Code Aurora isn't listed there, so look for it at [North Star](https://www.northstarfigures.com/prod.php?prod=17037).
